# Bundled font licences

These notices are copied with `public/` into every web/desktop frontend build.
Each OFL file includes its font's copyright statement and the full SIL OFL 1.1.

| Font | Author | Shipped licence | Source |
|---|---|---|---|
| Inter | Rasmus Andersson / Inter Project Authors | `OFL-Inter.txt` | `@fontsource/inter/LICENSE` |
| Geist | Vercel / Geist Project Authors | `OFL-Geist.txt` | `@fontsource/geist/LICENSE` |
| Geist Mono | Vercel / Geist Project Authors | `OFL-GeistMono.txt` | `@fontsource/geist-mono/LICENSE` |

All three are bundled as WOFF/WOFF2 subsets from the pinned npm packages. No
runtime font service is used.
See `docs/ASSETS.md` and `docs/third-party-notices.md` in the source repository.
