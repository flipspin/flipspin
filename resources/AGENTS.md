# Shared release assets

Paths are relative to the repository root. This directory owns icons, starter
content policy and bundled notices. Icon rendering scripts live beside their
sources. Preserve licensing notices and review generated assets visually.

Changes route through the ci area because packaging shares these assets across
applications. See `resources/icon/README.md` for icon generation commands and
`resources/default-songs/README.md` for the starter-content policy.
